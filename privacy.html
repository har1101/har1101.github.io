プライバシーポリシー

最終更新日: 2026-10-02

対象

このポリシーは、AI Builders Day 2026 運営チームが使う内部ツール（以下「本ツール」）に適用されます。本ツールを利用するのは運営メンバーだけです。

取得する情報

運営メンバーが自分の Google アカウントで認可した場合に、認可された範囲（scope）で次の情報を読み取ります。

  • Gmail: 運営用メールの件名・送信者・本文・ラベル
  • Google Drive / Docs / Sheets / Slides: 運営用フォルダ内のファイルのメタデータと内容

利用目的

取得した情報は、イベント運営のタスク整理、議事録の要約、運営メンバーへの通知、連絡の下書き作成にだけ使います。広告、販売、第三者への提供、機械学習モデルの学習には使いません。

保存と管理

OAuth の認可情報は Amazon Web Services 上で暗号化して保存し、運営メンバーだけがアクセスできるように管理します。処理結果は運営チームの Slack と GitHub リポジトリ（非公開）に記録します。

Google API Services User Data Policy への準拠

本ツールが Google API から受け取った情報の利用と他システムへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

認可の取り消しと削除

認可は Google アカウントのサードパーティ アクセス設定 からいつでも取り消せます。保存されたデータの削除は、下記の連絡先までご依頼ください。
